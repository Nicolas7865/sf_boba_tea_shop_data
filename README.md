# sf_boba_tea_shop_data

## Una agencia de marketing en San Francisco busca colaborar con tiendas locales de té de burbujas para una nueva campaña. como parte de esta iniciativa, planean visitar los establecimientos mejor calificados dentro de un radio de 10 millas del centro de su zona objetivo.

## Objetivo del análisis: Limpiar y analizar los datos calificados y ubicación de las tiendas para identificar cuáles cumplen con esos criterios y recomendar a cuáles debería visitar la agencia.
